# Gestión multi-oficina: un solo sistema para toda tu red inmobiliaria

Cuando una agencia crece a varias oficinas, el problema deja de ser "gestionar propiedades" y pasa a ser "coordinar equipos que no se ven entre sí". Cada sede con su Excel, sus WhatsApp, sus criterios distintos de seguimiento. La dirección pierde visibilidad y las oportunidades entre oficinas —un cliente de una sede que encaja con una propiedad de otra— simplemente no se detectan.

KageSan está preparado para operar como sistema único de varias oficinas, con permisos diferenciados y visión consolidada para dirección.

## Qué resuelve la gestión multi-oficina en KageSan

### Cartera compartida, visibilidad controlada
Todas las oficinas trabajan sobre el mismo sistema, pero cada equipo ve solo lo que le corresponde según los permisos configurados. Dirección, en cambio, tiene visión completa de todas las sedes.

### Matching entre oficinas
El motor de matching inteligente no se limita a la cartera de una sola oficina: puede identificar que un cliente de la sede A encaja con una propiedad de la sede B, algo prácticamente imposible de detectar manualmente.

### Reportes comparativos por oficina y por agente
Rendimiento, propiedades cerradas, tiempo medio de cierre y actividad, comparables entre sedes desde un único dashboard, sin pedir informes manuales a cada responsable.

### Estandarización de procesos
Los pipelines y flujos de trabajo se configuran una vez y se aplican de forma consistente en todas las oficinas, evitando que cada sede "invente" su propio proceso.

## Para quién está pensado

- Agencias con **2 o más oficinas físicas**
- **Franquicias inmobiliarias** que necesitan un estándar común entre franquiciados
- Redes que están **creciendo** y quieren evitar la fragmentación de datos antes de que se convierta en un problema

## Preguntas frecuentes

**¿Puedo empezar con una oficina y añadir más después?**
Sí, la estructura multi-oficina se puede activar a medida que la agencia crece, sin necesidad de migrar de sistema.

**¿Los agentes de una oficina pueden ver los datos de otra?**
Solo si así se configura. Los permisos son granulares por oficina, equipo o rol.

**¿Es necesario el plan Enterprise para tener varias oficinas?**
Para estructuras con múltiples sedes y necesidades de API o soporte dedicado, sí. Recomendamos hablar con el equipo comercial para dimensionar el plan correcto.
